            O que eu posso pedir

            Estes saem na hora, feitos pelo próprio motor, sem IA. Escreva do seu jeito: “tira essa pausa”, “tira a pausa”, “remove this pause”. O cursor e a seleção da linha do tempo vão junto com o pedido.

              O resto vai para o seu agente

              Pedidos livres (“dá um zoom quando ela fala water e põe um som de pop”) esperam na fila até o seu agente pegar: o Claude Code ou o Codex que você já usa, sem chave de API paga. No terminal dele, peça para rodar cli.ts agent-inbox <spec> --wait e seguir as instruções do JSON (o passo a passo está no README do EditAi, em “Editor com IA”). Ele só muda o vídeo por operações conferidas pelo motor. Quando o pedido não está claro, ele pergunta aqui, como “precisa de você”.

# Exemplos / Examples

Um exemplo por template, todos provados com material real (clipes de talking head 9:16 com voz). Nenhum arquivo aqui tem caminho de uma máquina: os clipes vêm de `${EDITAI_MEDIA}` e a saída do lote vai para `${EDITAI_OUT}`.

One example per template, each proven on real material (9:16 talking-head clips with voice). No file here holds a machine path: clips come from `${EDITAI_MEDIA}`, the batch writes to `${EDITAI_OUT}`.

| Arquivo / file | Template | Precisa / needs |
|---|---|---|
| `text-only.slots.json` | `text-only` | `clip-c.mp4` |
| `pov-app-screen.slots.json` | `pov-app-screen` | `clip-b.mp4`; a tela é `media/app-screen-placeholder.png` / the screen is the placeholder |
| `this-vs-that.slots.json` | `this-vs-that` | `clip-a.mp4`, `clip-c.mp4` |
| `talking-head-batch.json` | `talking-head-captions` via `cli.ts th-batch` | `clip-a.mp4`, `clip-b.mp4`, `clip-c.mp4` |
| `talking-head-broll-batch.json` | `talking-head-broll` via `cli.ts th-batch` (2.1.0) | os mesmos clipes; mídia do cliente opcional em `${EDITAI_OUT}/editai/broll/` (ex.: `water-glass.mp4`); o card pedido em 9,6 s precisa do editonny 1.0.0 / the same clips; optional client media in `${EDITAI_OUT}/editai/broll/`; the card asked at 9.6 s needs editonny 1.0.0 |

Os tempos, textos e regiões protegidas (olhos e boca) foram medidos em três clipes de teste de talking head (`clip-a`, `clip-b`, `clip-c`). Com os seus clipes, troque `hook_lines`, `protect_regions` e, no lote, `takes`, `words` e `script`.

Timings, texts and protected regions (eyes and mouth) were measured on three talking-head test clips (`clip-a`, `clip-b`, `clip-c`). With your own clips, change `hook_lines`, `protect_regions` and, in the batch, `takes`, `words` and `script`.

```bash
# Windows (Git Bash) / macOS / Linux
export EDITAI_MEDIA="/caminho/para/os/clipes" EDITAI_OUT="/caminho/para/a/saida"
bun lib/edit-engine/cli.ts from-template this-vs-that examples/this-vs-that.slots.json vs.plan.spec.json
bun lib/edit-engine/cli.ts render vs.plan.spec.json vs.mp4      # writes vs.spec.json (resolved) next to the MP4
bun lib/edit-engine/cli.ts qa vs.spec.json vs.mp4
bun lib/edit-engine/cli.ts th-batch examples/talking-head-batch.json
bun lib/edit-engine/cli.ts th-batch examples/talking-head-broll-batch.json   # B-roll automático / automatic B-roll
```

O lote com B-roll usa `broll_min_gap_s: 5.5` porque o vídeo tem 13,7 s: com 3 s de gancho, 2,5 s de CTA e 6 s entre itens só caberia um. Num vídeo de 45 a 60 s, deixe o padrão de 6 s. / The B-roll batch sets `broll_min_gap_s: 5.5` because the video is 13.7 s long; keep the 6 s default for 45 to 60 s videos.

`media/app-screen-placeholder.png` foi gerado por `bun lib/edit-engine/cli.ts placeholder-screen` e traz escrito PLACEHOLDER. É do squad, sem terceiros. / generated by the squad, no third-party content.
